### 概念

[插槽](https://v2.cn.vuejs.org/v2/guide/components-slots.html)

[作用域插槽](https://v2.cn.vuejs.org/v2/guide/components-slots.html#%E4%BD%9C%E7%94%A8%E5%9F%9F%E6%8F%92%E6%A7%BD)

核心是让父级组件访问子组件中的数据

>注意：父级模板里的所有内容都是在父级作用域中编译的；子模板里的所有内容都是在子作用域中编译的。

### 模板和jsx的两种处理方式

```jsx
// CurrentUser.vue
<script lang="ts">
  import Vue from 'vue'
  import { Component } from 'vue-property-decorator'
  @Component({
    name: 'CurrentUser'
  })
  export default class CurrentUser extends Vue {
    user = {
      firstName: 'firstName',
      lastName: 'lastName'
    }
    user2 = {
      firstName: 'zzzzz',
      lastName: 'kkkkkk'
    }
  }
</script>

<template>
  <span>
    {/* 通过v-bind将子组件的数据提供出去 */}
    <slot v-bind:user="user">{{ user.lastName }}</slot>
    <slot name="user2" v-bind:user="user2">{{ user.lastName }}</slot>
  </span>
</template>


// index.vue
<template>
  <current-user>
    {/* 通过v-slot绑定对应具名slot的数据 */}
    <template v-slot:default="slotProps">
      {{ slotProps.user.firstName }}
    </template>
    <template v-slot:user2="parentUser2">
      {{ parentUser2.user.firstName }}
    </template>
  </current-user>
</template>

```


```jsx
// CurrentSearch.jsx
@Component({
  name: 'CurrentSearch'
})
class CurrentSearch extends Vue {
  user = {
    firstName: 'firstName',
    lastName: 'lastName'
  }
  user2 = {
    firstName: 'zzzzz',
    lastName: 'kkkkkk'
  }

  render() {
    return <span>
      {/* 通过$scopedSlots访问具体的渲染函数并将子组件的数据传入 */}
      <div>{ this.$scopedSlots.user(this.user) }</div>
      {/* 常规具名slot */}
      {this.$slots.haha}
      <br></br>
      <div>{ this.$scopedSlots.user2(this.user2) }</div>
    </span>
  }
}

// index.jsx
@Component({
  name: 'Index',
  components: {
    CurrentSearch
  },
})
class Index extends Vue {
  render() {
    return <div>
      {/* scopedSlots传入具体的渲染函数，并通过函数参数拿到子组件的数据 */}
      <current-search scopedSlots={{
        user(user) {
          return <div>{user.lastName}</div>
        },
        user2(user2) {
          return <div>{user2.lastName}</div>
        },
      }}>
      <div slot="haha">haha</div>
      </current-search>
    </div>
  }
}

```
