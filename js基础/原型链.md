### prototype和__proto__的区别

1、对象具有属性__proto__，可称为隐式原型，一个对象的隐式原型指向构造该对象的构造函数的原型，这也保证了实例能够访问在构造函数原型中定义的属性和方法。(只是现在官方不推荐使用了，换成Reflect.getPrototypeOf())

```js
var obj = {}
console.log(Reflect.getPrototypeOf(obj) === obj.__proto__) // true
console.log(obj.__proto__ === Object.prototype) // true

function Foo(){}
var foo = new Foo()

console.log(foo.__proto__ === Foo.prototype) // true
```

2、方法(Function)。方法这个特殊的对象，除了和其他对象一样有上述_proto_属性之外，还有自己特有的属性——原型属性（prototype），这个属性是一个指针，指向一个对象，这个对象的用途就是包含所有实例共享的属性和方法（我们把这个对象叫做原型对象）。原型对象也有一个属性，叫做constructor，这个属性包含了一个指针，指回原构造函数。


### 通常的继承方法

- 原型链继承，将子类的prototype指向父类的实例

```js
function Parent(){}
function Sub(){}
Sub.prototype = new Parent()
Sub.prototype.constructor = Sub
```

- 原型继承，将子类的prototype设置为父类的prototype

```js
Sub.prototype = Parent.prototype
Sub.prototype.constructor = Sub
```

- 构造函数继承，在子类的构造函数中调用父类

```js
function Sub(){
    Parent.apply(this)
}
```
