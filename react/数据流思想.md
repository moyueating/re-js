### Flux的基本概念
Flux应用有3大部分组成，dispatcher,store和view，dispatcher负责分发事件，store负责保存数据同时响应事件并更新数据，view负责订阅store中的数据，并使用这些数据渲染相应的页面。


### Redux的基本概念

dispatch => action => [ middleware ] => reducer => store 

- 单一数据流  
- 状态是只读的  
- 状态修改均有纯函数完成  

### redux中间件

首先经过applyMiddleware处理
```js
function applyMiddleware(...middlewares) {
  return function(createStore){
    return function(reducer, initialState){
      const store = createStore(reducer, initialState)
      let chain = []

      const middlewareAPI = {
        getState: store.getState,
        dispatch: (action) => dispatch
      }

      chain = middlewares.map(middleware => middleware(middlewareAPI))
      dispatch = compose(...chain)(store.dispatch)

      return {
        ...store,
        dispatch
      }
    }
  }
}
```

// 第一层传入Store，第二层传入加强后的dispatch，最后执行原始的dispatch action
function logger(store){
  return function(next){
    return function(action){
      console.log('pre', store.getState())
      next(action)
      console.log('after', store.getState())
    }
  }

}
