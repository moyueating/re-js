### 捕获
正则表达式里分组模式以小括号来()表示分组，例如：/([a-z])/，多个小括号分组会以数字编号的形式保存在内存中。

```js
// 两个小括号分组存放在内存中的分别是hello -> $1  world -> $2，然后调换位置
var result = 'hello world'.replace(/([a-z]+)\s([a-z]+)/, "$2 $1")
```

```js
// 这个其实和上面的一样效果，不同的获取方式，正则运行后，将捕获的分组以$1-9的形式
var pattern = /([a-z]+)\s([a-z]+)/
pattern.exec('hello world')
console.log(RegExp.$1)
console.log(RegExp.$2)
```

#### 捕获的类型

- 前瞻捕获，exp1(?=exp2)，查找exp2前面的exp1
```js
// 将world前面的词去掉
var result = 'hello myworld'.replace(/[a-z]+(?=world)/, '') //hello world
```

- 后顾捕获，(?<=exp1)exp2，查找啊exp1后面的exp2
```js
// 将hello后面的词去掉
var result = 'hellomy world'.replace(/(?<=hello)[a-z]+/, '') //hello world
```

- 负前瞻，exp1(?!exp2)，查找后面不是exp2的exp1
```js
// 查找后面不是数字的词
var result = 'hello worldA234'.match(/[a-z]+(?!\d)/ig) // ['hello', 'world']
```

- 负后顾，(?<!exp1)exp2，查找前面不是exp1的exp2
```js
// 查找前面不是数字的词
var result = '12Ahello world'.match(/(?<!\d)[a-z]+/ig) // ['hello', 'world']
```


### 非捕获 
用 (?:) 表示，一旦设置了非捕获，那么正则中会分组但是不会再内存中存储相关的值
```js
var pattern = /(?:[a-z]+)\s([a-z]+)/
pattern.exec('hello world')
console.log(RegExp.$1) // world
console.log(RegExp.$2) // 
```
